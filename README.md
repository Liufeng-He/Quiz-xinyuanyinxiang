# 心院人格 H5

一个移动端优先的互动问卷：根据好感度、存在感与关注朝向生成 8 种拟人化心院画像，并给出专业标签、实验气质、CP 感、私人回信和匿名关键词云。

## 启动

项目不依赖第三方包，只需要 Node.js 18 或更高版本。

```powershell
npm start
```

浏览器打开：`http://127.0.0.1:4173`

Windows 也可以直接双击 `启动网页版.bat`，再打开上述地址。

如需更换端口：

```powershell
$env:PORT=8080
npm start
```

## 测试

```powershell
npm test
```

测试覆盖 8 种结果类型、分数边界、关键词近义词归并、提交接口、词云接口与静态页面服务。

## 数据说明

- 第 8 题的三个词提交到 `POST /api/v1/psychology-keywords`。
- 聚合词云来自 `GET /api/v1/psychology-keywords/cloud`。
- 服务端只在 `data/keywords.json` 中保存归并后的计数和词形频次，不保存姓名、答题 ID 或私人文本。
- 第 9 题私人文字仅在浏览器中生成个人回信，不会发送到服务端。
- 正式公开部署时，建议将词频存储替换为数据库，并将公开词云的最小展示频次设置为 3。
